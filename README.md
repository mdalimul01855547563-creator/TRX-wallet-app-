# TRX Wallet Registration App

A responsive mobile-friendly TRX (TRON) wallet registration application with dashboard functionality.

## Features

- User registration form with validation
- Responsive design for all devices
- TRX wallet dashboard with balance display
- Transaction history
- Bottom navigation
- Success notifications

## Technologies Used

- HTML5
- CSS3 (Flexbox, Media Queries)
- JavaScript (Form validation, DOM manipulation)
- Font Awesome Icons

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Fill out the registration form
4. Submit to see the TRX wallet dashboard
